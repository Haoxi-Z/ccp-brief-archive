# [Markets Media] 瑞士央行启动 Swiss Financial Ledger 探索项目

## 一句话


## 要点（日报自动生成）
瑞士央行与 UBS、SIX、苏黎世州银行、PostFinance、沃州州银行、巴塞尔州银行、Sygnum 及结算平台 Seturion 启动基于 DLT 的 Swiss Financial Ledger 探索项目，研究央行货币、商业银行货币与证券在同一平台交互，评估跨境（参照 Project Agorá）和境内交易处理、技术架构、治理与运营框架。瑞士央行强调现有 FMI 高效，项目仅为探索，不代表会上线或发行面向金融机构的代币化央行货币。背景：项目属 Project Helvetia 框架，建立在 BIS 与 IIF 的 Project Agorá 之上。
