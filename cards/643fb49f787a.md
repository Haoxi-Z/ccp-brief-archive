# [Finadium] 加拿大三方回购服务 CCMS 新增三类 GC 担保品篮子

## 一句话


## 要点（日报自动生成）
CIMPA、TMX Group 与 Clearstream 宣布，加拿大担保品管理服务（CCMS）已开始以省级政府债、加拿大按揭债券（CMB）和 NHA MBS 为担保品的回购交易，并为这三类资产新增 GC 篮子。CCMS 三方服务由 TMX 与 Clearstream 联合提供；加拿大政府债 GC 篮子已于 8 月上线，公共部门实体及公司债 GC 篮子将在未来几个月推出。
